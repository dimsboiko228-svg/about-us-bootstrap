# About Us — Bootstrap 5

Адаптивна навчальна сторінка для завдання з лекції 3.

## Файли
- `index.html` — сторінка сайту.

## Публікація через GitHub Pages
1. Створіть новий репозиторій на GitHub, наприклад `about-us-bootstrap`.
2. Завантажте `index.html` у корінь репозиторію та натисніть **Commit changes**.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/(root)`, натисніть **Save**.
6. Зачекайте завершення публікації. Посилання зазвичай має формат:
   `https://ВАШ-USERNAME.github.io/about-us-bootstrap/`

Замініть `ВАШ-USERNAME` на власний GitHub username. Після публікації надішліть викладачу посилання на репозиторій і на сторінку Pages.
